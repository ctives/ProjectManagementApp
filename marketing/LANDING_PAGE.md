A: Yes! View the code on GitHub, contribute, or self-host your own version. [GitHub link]

A: We're developers who got tired of complex, expensive project management tools that don't respect privacy. We built the tool we wished existed. [About page link]

## CONVERSION OPTIMIZATION

### Above the Fold Checklist
- [ ] Clear value proposition in <5 words
- [ ] Obvious primary CTA
- [ ] Trust indicators visible
- [ ] Visual showing product
- [ ] No jargon or complexity

### CTA Best Practices
- **Primary CTA**: "Start Organizing Free" (action-oriented, includes benefit, mentions free)
- **Secondary CTA**: "Watch Demo" (low commitment)
- **Throughout page**: Multiple CTAs at natural break points
- **Button copy**: Action verbs, benefit-focused, create urgency without pressure

### Trust Building Elements
- Open source badge
- Privacy promise front and center
- Transparent about limitations
- Real use cases
- Technical credibility (modern stack)
- No hidden costs messaging

### A/B Testing Ideas
1. Hero headline variations (privacy vs. simplicity vs. speed)
2. CTA button color (white vs. solid purple vs. gradient)
3. Feature order (privacy first vs. speed first)
4. Comparison table presence (include vs. exclude)
5. Demo video vs. animated preview
